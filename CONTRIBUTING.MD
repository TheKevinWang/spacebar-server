# Contributing

Welcome! This independent Spacebar fork accepts AI-generated and AI-assisted
contributions, including code, tests, documentation, and issue reports.

We aim to keep up with upstream Spacebar and support local testing of Discord C2
profiles such as [Discordx](https://github.com/TheKevinWang/discordx). Contributions
should be useful beyond a single local setup.

## Issues and pull requests

Use [this fork's issue tracker](https://github.com/TheKevinWang/spacebar-server/issues)
to report bugs or discuss larger changes. Check existing issues and pull requests
first. For a bug report, include the affected version, expected and actual
behavior, and a minimal example when possible.

Keep pull requests focused on one problem. Explain what changed, why it helps,
and how it was validated. Follow the existing code style and include relevant
regression coverage for behavior changes. Note any checks you could not run.

## AI-assisted work

AI involvement is welcome and is not a reason to reject a contribution. Please
mention material AI assistance in the issue or pull request description.

You remain responsible for understanding and reviewing the submitted work,
checking its correctness, and ensuring that you have the right to contribute it.
Review is based on the contribution's quality, usefulness, and maintainability.

## Upstream and licensing

This policy replaces the upstream AI contribution restriction for submissions
to this fork only. Upstream Spacebar has its own contribution rules.

Preserve existing copyright notices and attribution. Contributions are made
under this repository's existing [GNU AGPLv3 license](COPYING).
